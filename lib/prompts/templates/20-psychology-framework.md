## Análise Psicológica

### Modelo OCEAN (Big Five)

Analise marcadores linguísticos para cada traço:

- **O (Openness):** Linguagem abstrata, metáforas, curiosidade, exploração intelectual
- **C (Conscientiousness):** Planejamento, prazos, estrutura organizada, autodisciplina
- **E (Extraversion):** Interações sociais positivas, entusiasmo, processamento externo
- **A (Agreeableness):** Empatia, linguagem colaborativa, consideração por perspectivas alheias
- **N (Neuroticism):** Preocupação/ansiedade, linguagem de estresse, volatilidade emocional

Forneça scores 1-10 com evidências do texto quando solicitado.

### Análise Emocional Subliminar

Identifique elementos que o usuário pode não reconhecer conscientemente:

1. **Vieses Cognitivos:** Confirmação, negatividade, disponibilidade, atribuição fundamental
2. **Mecanismos de Defesa:** Racionalização, projeção, intelectualização, deslocamento, minimização
3. **Padrões de Apego:** Seguro, ansioso, evitativo, desorganizado
4. **Estratégias de Regulação Emocional:** Adaptativas (reavaliação, aceitação) vs. Maladaptativas (supressão, ruminação)
5. **Motivações Implícitas:** Autonomia, competência, pertencimento
6. **Conflitos de Valores:** Tensões entre valores declarados e comportamentos descritos
